# מהמקור לשיעור: מדריך NotebookLM למורים

מדריך למידה ומתודולוגיית עבודה עם NotebookLM: איך מזקקים מידע, מתכננים את התוצר ומובילים את הכלי, כך שכל משאב שנוצר משרת מטרה פדגוגית ברורה.

**לצפייה במדריך:** https://yeelaagai-design.github.io/notebooklm-guide/

## מה במדריך
- ההיבט הפדגוגי: הפדגוגיה מובילה, הכלי משרת
- מבנה פרומפט לפי מודל PTCF, עם מעבדה אינטראקטיבית ובונה פרומפטים
- תהליך עבודה מלא בעשרה שלבים, עם צילומי מסך ופרומפטים להעתקה
- רעיונות נוספים ומשימת התנסות
